# 收件箱转正规则（scripts/inbox-promote.md）

> 本文件是「AI学习库·收件箱转正」自动化的**权威规则**。自动化 prompt 引用本文件，避免规则分散、改一处要改多处。
> 适用范围：`D:\Obsidian\AI学习`
> 配套：SCHEMA.md（字段规范）· 90-模板（模板）· outputs/daily-report.md（黑匣子）· MAINTENANCE.md §2

## 触发条件
- 仅处理 `00-收件箱/*.md` 中**同时满足**：
  - `status: reviewed`（用户阅读确认后手动改的）
  - `tags` 含 `AI对话沉淀`
- `draft` / `wip` 一律不动；不改 `reviewed` 的草稿永远留在收件箱，绝不被动。

## 目标子目录判定（转正落点）
按以下优先级决定写入 `20-笔记/` 的哪个子目录（子目录只用于归类，双链不受影响）：
- `type: concept` → `20-笔记/概念/`
- 标题以 `AI开窍计划` 开头 → `20-笔记/课程/`
- 标题含 `沉淀` 或属对话沉淀机制笔记 → `20-笔记/沉淀/`
- 其余 → `20-笔记/技能与工具/`

## 转正步骤（每条）
1. 改写 frontmatter 为 20-笔记 规范（以 SCHEMA.md 为准，参考 90-模板）：
   - `type` 保持（默认 `note`）
   - `title` 保持
   - `created` 保持，`updated` 改为今天
   - `tags` 去掉「待整理」，保留其他
   - `status: reviewed`（终态：已读已消化）
   - `confidence` 按内容定（高 / 中 / 低）
   - `uncertainty`：可选，诚实写不确定或待核实内容
   - `moc`：若空或只有占位，填 `MOC-AI入门与基础`；否则保持
   - `related`：若有可关联笔记则填
2. 在 **目标子目录**/<同名文件>.md 写入改写后的笔记（目标子目录见上节）。
3. 在对应 `10-MOC/<MOC名>.md` 末尾追加一行 `- [[<标题>]]`（已存在则跳过）。
4. 把原收件箱文件**移动**到 `00-收件箱/已转正/`，frontmatter `status` 改 `archived`，加 `promoted_to: <目标子目录>/<文件名>.md`。

## 收尾（维护即快照）
5. 向 `outputs/daily-report.md` 追加本次记录：按今天日期 `## YYYY-MM-DD` 分组（已有则追加其下，无则新建标题）；格式：
   `- 转正 [[<标题>]]：<原路径> → <目标子目录>/<文件名>.md；MOC 加链；原文件移入 已转正/`
   若无待转正笔记：在今日标题下记「无待转正笔记。」（今日标题不存在则先创建再记）。
6. 在 `D:\Obsidian\AI学习` 执行 `git add -A && git commit -m "chore: 每日收件箱转正 YYYY-MM-DD"`。
   若 git 报 `nothing to commit` 则正常跳过，不要报错。

## 安全红线
- 只处理 `reviewed` + `AI对话沉淀`；不删除任何文件（仅移动到 `已转正/`）。
- 不改动与本次转正无关的文件。
- 涉及删除 / 覆盖 / 敏感 / 事实冲突，先确认再执行。
