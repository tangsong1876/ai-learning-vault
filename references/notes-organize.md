# 20-笔记 整理规则（scripts/notes-organize.prompt.md）

> 本文件是「AI学习库·20-笔记整理」自动化的**权威规则**，对标项目知识库 `scripts/daily-maintenance.prompt.md` 的每日维护逻辑。
> 作用：把散落在 `20-笔记/` 根目录、或应重新归类的笔记，按内容类型落入对应子目录，并同步 INDEX，保持库「不乱」。
> 适用范围：`D:\Obsidian\AI学习`
> 配套：SCHEMA.md（字段规范）· INDEX.md（总索引）· MAINTENANCE.md §2 · 20-笔记/README.md（分类说明）

## 目标目录
`20-笔记/` 下按类型分四子目录：
| 子目录 | 内容 | 判定 |
|---|---|---|
| `概念/` | 单点概念笔记 | `type: concept` |
| `课程/` | 课程系列笔记 | 标题以「AI开窍计划」开头 |
| `技能与工具/` | 独立技能/工具/教程 | 其余 `type: note` 且非沉淀 |
| `沉淀/` | 对话沉淀机制笔记 | 标题含「沉淀」或属对话沉淀机制 |

## 执行步骤（每次运行）
1. 用 Glob 列出 `D:\Obsidian\AI学习\20-笔记\*.md`（仅根目录），找出所有**未归入子目录**的笔记文件（排除 `README.md`）。
2. 对每个散落文件：Read 解析 frontmatter 的 `type` 与标题，按上表判定目标子目录。
3. 用移动（保留文件，不重写内容）把文件移入目标子目录。**双链按标题解析，移动不影响 `[[...]]` 链接，无需改任何笔记正文或 MOC。**
4. 同步更新 [[INDEX]]：确保该笔记出现在对应分类表（概念/课程/技能与工具/沉淀）下，链接用 `[[标题]]`；若 INDEX 中链接标题与实际文件名不一致（如「第四课」vs「第四节」），以**实际文件名**为准修正。
5. 检查并记录（列入待确认，不直接改）：重复内容、事实冲突、过期信息、缺少 `source` 的内容、命名不规范的标题。
6. 向 `outputs/daily-report.md` 追加本次整理记录（按 `## YYYY-MM-DD` 分组）：`- 整理 [[<标题>]]：20-笔记/根 → 20-笔记/<子目录>/`（无散落则记「20-笔记 无散落笔记，无需整理。」）。
7. 在 `D:\Obsidian\AI学习` 执行 `git add -A && git commit -m "chore: 20-笔记整理 YYYY-MM-DD"`（nothing to commit 则跳过）。

## 安全边界（必须遵守）
- 只在 `D:\Obsidian\AI学习` 内操作，不触碰其他目录。
- 不删除、不重写笔记正文；只移动文件位置。
- 不改变 `status` / `type` 等业务字段（归类只看既有字段）。
- 涉及删除、覆盖、敏感信息或事实冲突，一律不直接执行，只列入待确认清单。

完成后用简洁中文总结本次归类数量与待确认项。
